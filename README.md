# ShellBoss

Tabbed terminal with per-tab todos, saved files and Claude Code integration

## Install

```sh
brew install --cask nikolainobadi/nn/shellboss
```

## Tab activity

For programs that report OSC 7501 status, such as Claude Code, ShellBoss shows a spinner beside the tab and terminal titles while work is in progress and a pulsing orange indicator when input is needed. Your manually assigned tab status reappears when live activity ends.

When reported activity ends on a background tab, including completion or error, an alert outline remains until you select that tab. Program-provided activity titles can also update tab titles, respecting your title-update setting and each tab’s title lock.
